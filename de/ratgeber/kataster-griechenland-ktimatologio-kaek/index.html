Das griechische Kataster (Ktimatologio) und die KAEK erklärt

Was das griechische Kataster erfasst, wie Sie die KAEK einer Immobilie auf der öffentlichen Karte finden, welche Dokumente es ausstellt und auf welche Fehler Sie achten sollten.

Was das Kataster ist

Das griechische Kataster (Ktimatologio) ist das nationale Register für Grundstücke und Gebäude. Jede Immobilie hat eine KAEK-Nummer, eine Form auf der Karte und einen Eintrag darüber, wer welches Recht hält.

So nutzen Sie es als Käufer

  • Suchen Sie die Immobilie auf der öffentlichen Karte (maps.ktimatologio.gr) nach KAEK oder Adresse.
  • Vergleichen Sie Form und Fläche mit dem Vertrag und mit dem, was Sie gesehen haben.
  • Fordern Sie Katasterauszug und Katasterplan über Ihren Anwalt oder Ingenieur an.

Fehler, auf die Sie achten sollten

Die Ersteintragungen beruhen auf Erklärungen der Eigentümer: falsche Fläche, falsche Grenzen, ein fehlendes Gebäude oder „unbekannter Eigentümer“ kommen vor. Bei einer Immobilie mit offenem Berichtigungsverfahren sollten Sie das Tempo drosseln.
